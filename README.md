# ProteinPlus – GitHub Pages

Statische Website für Support, Datenschutz und Impressum.

## Veröffentlichung
1. Neues öffentliches Repository `protein-plus-web` auf GitHub erstellen.
2. Alle Dateien aus diesem Ordner ins Repository hochladen.
3. In **Settings → Pages → Build and deployment** die Quelle **Deploy from a branch**, Branch `main`, Ordner `/ (root)` auswählen.
4. Unter `https://olivertwist72.github.io/protein-plus-web/` prüfen.

**Vor Veröffentlichung:** Vollständige Anbieteranschrift in `impressum.html` ergänzen; Datenschutzerklärung auf den finalen App-Build prüfen.

Farben zentral in `style.css` unter `--green` und `--orange` anpassbar.
